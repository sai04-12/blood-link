Welcome to Blood Link

Blood Link is a student project prototype that demonstrates donor registration, information storage and blood group searching.

Our Main Features

🩸 Donor Registration

Explore a simple registration form for entering fictional donor details.

🔍 Search Donors

Search saved demo entries using city and blood group.

💾 Information Storage

Demonstrates how browser storage can save and retrieve information.

Our Purpose

To explore how technology can make blood donor information easier to organize and search.

Project Demonstration: This website uses browser Local Storage and fictional test entries. It does not connect users with verified donors or arrange actual blood donations.
