# 🩸 Blood Link

> **Connect. Donate. Save Lives.**

Blood Link is a web application prototype designed to streamline blood donation by connecting donors with recipients, providing an easy-to-use search by blood group and city, and demonstrating local storage persistence for donor records and blood requests.

---

## 🌟 Features

- **Donor Registration (`register.html`)**: Register donor details including name, blood group, age, city, and phone number with validation.
- **Find Donors (`find.html`)**: Search and filter registered donors by city and blood group.
- **Request Blood (`request.html`)**: Submit emergency or scheduled blood requests specifying patient details, required blood unit, and hospital information.
- **Dashboard (`dashboard.html`)**: Track total registered donors, total blood requests, and quick action shortcuts.
- **Login Portal (`login.html`)**: Quick access demo login session.
- **About Us (`about.html`)**: Learn about the Blood Link mission, purpose, and demonstration scope.

## 🚀 Live Deployment on Vercel

This project is fully ready for deployment on [Vercel](https://vercel.com):

1. Push this repository to GitHub: `https://github.com/sai04-12/blood-link`
2. Go to [vercel.com](https://vercel.com) and log in.
3. Click **Add New Project** -> **Import Git Repository**.
4. Select `blood-link` from your GitHub repositories.
5. Click **Deploy**. Vercel will automatically build and deploy your site with a live URL (e.g. `https://blood-link.vercel.app`).
